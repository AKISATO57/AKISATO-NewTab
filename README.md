# AKISATO NewTab

AKISATO 灯塔是一个可自定义的浏览器新标签页扩展，支持书签胶囊、浏览器收藏夹同步、搜索建议、背景壁纸、主题颜色和收藏卡片。

## 安装扩展

1. 打开 Edge 或 Chrome 的扩展管理页。
2. 打开“开发人员模式”。
3. 选择“加载解压缩的扩展”。
4. 选择本仓库的 `extension` 文件夹。

`extension` 文件夹就是可直接加载的插件本体，保留了当前版本的运行文件、图标和回归检查。

## 单 HTML 版本

`single-html/index.html` 是当前版本的界面、动画、设置、搜索、壁纸和收藏卡片的单文件版本，直接用浏览器打开即可使用；由于普通 HTML 页面没有浏览器扩展 API，它会使用页面内收藏逻辑，不启用扩展专属的原生新标签页覆盖和浏览器收藏夹实时同步。可进入：https://akisrch.netlify.app 使用网页版

## 目录

```text
extension/      浏览器扩展本体，可直接加载
single-html/    单 HTML 版本
```

## 说明

- 壁纸预设使用远程图片地址，需要网络连接。
- `extension/app.js` 是浏览器运行用的打包文件；其余 JavaScript 和 CSS 文件可直接修改。
